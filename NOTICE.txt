internal/css/csstree (with its tokenizer and definitionsyntax
subpackages) is a translation into Go of csstree v3.2.1
(https://github.com/csstree/csstree), a CSS tokenizer, parser, walker,
generator, and value lexer written in JavaScript by Roman Dvornov. The
translation was made file by file in github.com/typelate/csstree, was
copied into github.com/typelate/htt, and was copied from there into this
repository with import paths rewritten; each Go file names the upstream
file it was translated from. csstree is distributed under the MIT
license, reproduced below as that license requires. The same text is in
internal/css/csstree/LICENSE.
